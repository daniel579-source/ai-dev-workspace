# ADR-0001：部署形態採單機桌面程式

- 日期：2026-10-15
- 狀態：已接受
- 確認者：repo owner（daniel579-source）
- 對應 ticket：Wayfinder「部署形態：單機或 Edge Server 加用戶端」

## 背景

系統規格書 v2 提議採主從式架構：由 Edge Server 集中算力，用容器部署 AI 與資料庫，前端打包成單一執行檔。這個提議的主要理由是集中 AI 運算，但離線 LLM 與向量資料庫已經排除在第一階段之外。

已確認的使用情境與環境：

- 分析通常由**一位工程師**拿到 LOG 後在自己的電腦上進行，分析完再把結論告訴別人；不需要多人同時查看同一份已匯入的資料。
- Layout 一個倉庫通常只建一次，之後多人重複使用。
- 工程師電腦**不能自行安裝軟體**，也**連不到外網**。
- 分析可能在**現場**或**出差**時進行，網路不一定穩定。
- 工程師電腦都是 Windows 10／11 64 位元。
- 樣本 LOG 一天約 20 MB（見 `docs/log-format-notes.md` O-016）；需求寫的每日 100 MB～10 GB 尚待確認。

## 決策

1. 系統為**單機桌面程式**：LOG 匯入、解析、索引、Layout 編輯與回放，全部在工程師自己的電腦上執行，資料存在本機。
2. 交付形式為**免安裝執行檔**，支援 **Windows 10／11 64 位元**，**完全離線**運作，不依賴任何網路服務。
3. **Layout 存成檔案**，透過共用資料夾或版本控管分享。
4. 新版放在**內部共用資料夾**，由工程師自行複製替換，**不做自動更新**。新版必須能讀取舊版產生的資料（索引、Layout 檔）。
5. **儲存層必須設計成可替換**，保留日後改為伺服器共用的可能。

2026-10-16 #29 補充：「完全離線」已在開發電腦驗證：冒煙測試（`OfflineSmokeTests`）以 `netstat` 確認執行期間（匯入、建立索引、搜尋、播放、Layout 編輯器）沒有任何網路端點；程式碼中沒有網路相關的 API。乾淨、離線的 Windows 10 實機確認見 ADR-0007 第 2 點。

## 理由

- 使用情境是單人分析，沒有集中共用資料的需求。
- LLM 已排除，不再需要集中運算。
- 樣本量級在單機能力範圍內。
- 不能安裝軟體、沒有外網、現場或出差時可能沒有網路，三者都指向免安裝、離線的單機程式。
- 真實 LOG 不會離開工程師的電腦，最符合 `CLAUDE.md` 3.6 節的資安原則。

## 考慮過的替代方案與捨棄原因

| 方案 | 捨棄原因 |
|---|---|
| Edge Server 集中匯入與儲存，加上用戶端（v2 規格提議） | 沒有多人共用的需求；需要另外申請與維運伺服器；現場或出差時可能連不到伺服器 |
| Web 應用程式（伺服器＋瀏覽器） | 需要伺服器；或需要在本機另外跑服務，不符合免安裝的條件 |
| 既有 LOG 平台（自架） | 需要伺服器；跨設備時間軸、Layout 回放、原始行追溯難以客製 |

## 尚存風險

| 風險 | 影響 | 緩解方式 |
|---|---|---|
| 實際量級接近每日 10 GB | 單機的匯入速度、查詢速度、磁碟空間可能不足 | 在「儲存與索引候選方案比較」中以樣本量與放大量級實測 |
| 日後出現多人共用的需求 | 需要把儲存層搬到伺服器 | 儲存層設計成可替換（決策第 5 點） |
| 各工程師電腦上的版本不一致 | 同一份 Layout 或資料在不同版本表現不同 | 資料檔帶版本號；新版必須能讀舊版資料 |
| 本機存放真實 LOG | 電腦遺失或外借時資料外洩 | 在「敏感資訊處理與存取權限」中處理 |

## 後續驗證方式

- 以樣本（一天約 20 MB）與放大後的量級（例如 1 GB、10 GB）實測匯入時間、查詢回應時間與磁碟用量。
- 在一台符合 IT 限制（不能安裝、沒有外網）的工程師電腦上，確認執行檔能直接執行。

## 影響範圍

- **LOG 取得與匯入方式**：改為在本機匯入。
- **用戶端技術選型**：限制為 Windows 10／11 64 位元、免安裝、離線、可打包成執行檔。
- **儲存與索引候選方案比較**：只比較可以內嵌在程式中的方案；需要另外架設伺服器的方案不在範圍內。
- **敏感資訊處理與存取權限**：單人使用、本機資料，存取控制主要依賴作業系統帳號。
