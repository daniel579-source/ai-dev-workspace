# ADR-0012：壓縮檔的讀取方式

- 日期：2026-10-16
- 狀態：已接受
- 確認者：repo owner（daniel579-source）
- 對應 ticket：#18 完整匯入與案件管理
- 相關決策：ADR-0002（接受資料夾、7z、zip）、ADR-0007（C# + .NET 10、self-contained 發佈）

## 背景

- ADR-0002 決定匯入接受資料夾，以及 7z、zip 壓縮檔，而且原始壓縮檔要整份保存在案件內。
- .NET 內建 zip 的讀取，但沒有 7z。讀取 7z 需要另外選擇套件或工具，屬於技術選型（CLAUDE.md 第 3.2 節）。
- 程式以 self-contained 單一資料夾發佈，目標是 Windows 10／11 64 位元（ADR-0001、ADR-0007）。
- 壓縮檔來自倉儲電腦，內容不受本程式控制；解開時不能寫到目的資料夾以外的位置。

## 決策

1. **7z**：使用 7-Zip 的 **`7za.dll`**（NuGet 套件 `7z.Libs` 26.4.0，只附帶 **x64** 版），加上 **Squid-Box.SevenZipSharp.Lite** 1.6.2.24（只含解開功能）。
   - 不使用 `7z.dll`：它支援較多格式，但含 **unRAR 的授權限制**；`7za.dll` 只含標準格式，授權單純為 LGPL。
   - `7za.dll` 與授權說明隨程式放在 `7z\` 子資料夾；授權為 **LGPL**（7-Zip、SevenZipSharp）。
2. **zip**：使用 .NET 內建的 **System.IO.Compression**。實作時確認 `7za.dll` **不支援 zip**（開啟 zip 時回報「Invalid archive」）。
3. **安全**：解開前先檢查每個項目的路徑；任何項目的路徑跑出目的資料夾時（例如 `../`），**整個壓縮檔拒絕匯入**，不寫出任何檔案。
4. 解開到案件內的暫存區（`staging\`），掃描、分類後搬進 `raw\`；匯入完成或取消後清除暫存區。

## 理由

- 7-Zip 本身的解開速度最快、對 7z 格式的支援最完整（使用者選定）。
- 只附帶 `7za.dll`，避開 unRAR 的授權限制；只附帶 x64 版，符合目標平台，也減少發佈的檔案。
- zip 用內建功能，不需要額外的原生程式碼。
- 先檢查路徑再解開，避免惡意或損壞的壓縮檔寫到案件以外的地方（zip slip）。

## 考慮過的替代方案與捨棄原因

| 方案 | 捨棄原因 |
|---|---|
| SharpCompress（純 .NET，MIT） | 不需要原生 DLL，但解開大型 solid 7z 比 7-Zip 慢 |
| 7z.dll + SevenZipSharp | 支援格式較多，但含 unRAR 的授權限制 |
| 附帶 7za.exe，以外部程式解開 | 實作最簡單，但錯誤處理與進度回報較粗略 |
| 7z 與 zip 都用 7za.dll | 7za.dll 不支援 zip |
| 第一版只支援 zip | 不符合 ADR-0002 |

## 尚存風險

| 風險 | 影響 | 緩解方式 |
|---|---|---|
| 只附帶 64 位元的 7za.dll | 32 位元環境無法解開 7z | 目標平台為 64 位元（ADR-0001）；32 位元時明確回報錯誤 |
| 隨程式附帶原生 DLL 並遵守 LGPL | 發佈時漏掉 DLL 或授權說明 | 建置與發佈時自動複製；發佈後確認 `7z\` 資料夾內容 |
| SevenZipSharp 依賴較舊的 System.Configuration.ConfigurationManager 4.5.0 | 日後出現安全性警告 | 建置時把警告當成錯誤，出現時再評估更新或替換 |
| zip 內的檔名不是 UTF-8 也沒有標示編碼 | 檔名解碼錯誤，無法辨識日期與模組 | 目前樣本的檔名都是英數字；遇到時再處理 |

## 後續驗證方式

- 以虛構資料確認資料夾、7z、zip 三種來源的匯入結果相同（#18 的測試）。
- 在乾淨、離線的 Windows 10 上確認 self-contained 發佈可以解開 7z（與 ADR-0007 的待測項目一起進行）。
- 取得真實的 LOG 壓縮檔後，確認解開時間與格式（是否為 solid、壓縮方式）。

## 影響範圍

- **匯入**（ADR-0002）：壓縮檔整份複製到案件的 `sources\`，解開後的檔案放在 `raw\`。
- **發佈**（ADR-0007）：發佈資料夾多了 `7z\7za.dll` 與授權說明。
