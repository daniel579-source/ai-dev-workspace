# ADR-0028：Conv 搭配導軌移動

- 日期：2026-11-26
- 狀態：**已接受**
- 確認者：repo owner（決策內容與待決項目 1b、2a、3b、4b、5a、6a、7b，2026-11-26）
- 相關 ADR：ADR-0005（回放的狀態推導，第 10 點搬送機沿導軌移動）、ADR-0006（Layout 模型與設定檔，第 14 點導軌）、ADR-0026（Conv）
- Ticket：#212

## 背景

使用者要求 Conv 也可以選擇搭配導軌移動（例如裝在軌道上、在幾條輸送線之間平移的輸送設備）。實際設備依各廠仕樣討論，不限定某一廠；**目前的 LOG 沒有這種設備的紀錄**，不知道 LOG 會不會記錄它的位置或移動目標。

改動前只有搬送機（STV）與 RM 可以指定導軌，回放時依命令的派送與抵達沿導軌移動（ADR-0005 第 10 點、ADR-0019）；Conv 固定在 Layout 擺放的位置。

## 決策

1. **設定**：Conv 可以指定一條導軌，沿用既有的 `rail` 欄位（2a）；只開放 Conv，工站點不開放（3b，Jev 0.84）。導軌必須在同一層、同一個層段（和搬送機相同的檢查）。有 Conv 指定導軌時格式版本為 **13**。Layout 編輯器的屬性面板以下拉選單選擇導軌。
2. **位置依貨物推估**（1b、5a）：
   - 貨物進入這個 Conv 時（讀到棧板、命令抵達等），Conv 對齊貨物**前一個位置**的設備；
   - 貨物離開這個 Conv 時（被搬送機、RM、電梯取走或送到其他設備），Conv 對齊貨物**下一個位置**的設備；
   - 對齊點是那個設備中心在導軌上的投影（儲位取那一排料架那一列的中心）；設備在不同樓層時不對齊。
   - 貨物前一個（或下一個）位置不明時，Conv 維持目前位置；還沒移動過時在 Layout 擺放的位置（6a）。
3. **移動的畫法**（7b）：從上一次對齊的時刻到這次對齊之間，依時間比例沿導軌內插移動；第一次對齊之前沒有起點的時間，直接畫在對齊點。Conv 不在 Layout 擺放的位置時一律標示**推估**（虛線）。Conv 上的貨物跟著移動。
4. **輸送線**畫在 Layout 擺放的位置，不跟著 Conv 移動（4b，Jev 0.56）。
5. **元素狀態**顯示位置的依據（例如「推估：對齊「搬送機 1」（貨物離開）」）與造成它的事件。

## 理由

- 使用者決定以貨物推估位置（1b）：LOG 沒有這種設備的紀錄，貨物進出時一定在交接的設備旁邊，是目前唯一的依據。
- 沿用 `rail` 欄位與搬送機相同的編輯方式與檢查，使用者不必學新的操作（2a）。
- 工站點一端給使用者操作，不在軌道上移動（3b）。
- 輸送線維持擺放位置，Layout 的配置一目了然（4b）。

## 考慮過的替代方案與捨棄原因

| 方案 | 捨棄原因 |
|---|---|
| 比照搬送機，依命令的派送與抵達移動 | LOG 沒有 Conv 被派送的紀錄（1a；Jev 0.20） |
| 只畫導軌、位置固定，等 LOG 樣式確認後再推導 | 使用者要先能依貨物推估（1c；Jev 傾向此案 0.79，信心度 0.68） |
| 另設新欄位 | 使用者決定沿用 rail（2b） |
| 工站點一起開放 | 3a；Jev 0.08 |
| 輸送線的端點跟著 Conv 移動 | 4a；Jev 0.22 |
| 只在貨物進入時對齊；或只看相連的輸送線 | 5b、5c；Jev 0.11、0.20 |
| 前一個位置不明時移到導軌起點 | 沒有依據（6b；Jev 0.23） |
| 在事件時刻直接跳到新位置 | 使用者決定依時間內插（7b；Jev 傾向直接跳 0.86，信心度 0.72） |

## 尚存風險

| 風險 | 影響 | 因應 |
|---|---|---|
| 兩次對齊之間隔很久時，Conv 在這段時間緩慢移動 | 畫面上的移動時間不代表實際 | 畫面標示推估；元素狀態寫出依據 |
| 位置完全是推估 | 與實際位置可能不同 | 實際設備的 LOG 有位置紀錄時，改以 LOG 推導，推估當備用 |
| 有 Conv 指定導軌的設定檔為格式版本 13 | 0.17.1 以前的程式打不開 | 發佈時一起更新；沒有用到時不變 |

## 後續驗證方式

- 以虛構資料的單元測試：進入時對齊前一個設備、離開時對齊下一個設備、前一個位置不明時不動、兩次對齊之間依時間內插、第一次對齊直接到位、不同樓層不對齊、格式版本 13 與存檔前檢查。
- 冒煙測試：Layout 編輯器替 Conv 指定導軌後存檔。
