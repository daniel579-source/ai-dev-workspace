# ADR-0029：主畫面的面板可以關閉，「視窗」選單開啟或關閉

- 日期：2026-11-26
- 狀態：**已接受**
- 確認者：repo owner（決策內容與待決項目 1a、2a、3（只有還原預設版面才恢復）、4a、5a、6b，2026-11-26）
- 相關 ADR：ADR-0008（回放與畫面，第 7 點 Docking 版面）
- 取代：ADR-0008 第 7 點「面板不能關閉也不能隱藏，避免找不回來」

## 背景

主畫面是 Docking 版面，有 13 個面板：案件、搜尋、事件清單、Layout 回放、時間軸、詳細資訊、元素狀態、命令、設備狀態表、未對應、知識庫、原始 LOG、異常紀錄。ADR-0008 第 7 點規定面板不能關閉也不能隱藏，避免使用者找不回來。

使用者要求：每個面板都可以單獨關掉；在上方「版面」選單旁新增「視窗」選單，可以開啟或關閉任一面板。

## 決策

1. **13 個面板都可以關閉**（5a，Jev 0.94）：面板標題列有關閉按鈕。關閉是「隱藏」，不是移除。
2. **「視窗」選單**（4a，Jev 0.66）：放在「版面」選單旁，列出 13 個面板（勾選＝顯示中），點一下開啟或關閉；最後是「全部顯示」。
3. **重新開啟時回到關閉前的位置與大小**（1a，Jev 0.70）。
4. **關閉的狀態存在版面檔**（2a）：重新開啟程式後仍然關閉。
5. **預設版面與還原**（3，使用者決定）：
   - 切換「回放」「搜尋」預設版面時，只把**目前顯示中的面板**依該版面重新排列，使用者關掉的面板維持關閉（之後從「視窗」選單開啟時放在該版面中的位置）；
   - 只有「**還原預設版面**」才恢復初始排列、所有面板重新顯示；
   - 版面檔損壞或來自舊版程式而改用預設版面時，也是所有面板都顯示。
6. 決策紀錄另開本 ADR，取代 ADR-0008 第 7 點的那一句（6b）。

## 理由

- 面板多、畫面有限，使用者依工作需要決定看哪些。
- 原本擔心關掉後找不回來：「視窗」選單一直列出所有面板，「還原預設版面」可以一次恢復。
- 隱藏（不是移除）讓面板回到原本的位置，不必重新拖曳排列。

## 考慮過的替代方案與捨棄原因

| 方案 | 捨棄原因 |
|---|---|
| 維持不能關閉 | 使用者要求可以關閉 |
| 重新開啟時一律以浮動視窗開啟 | 要再拖回原位（1b，Jev 0.15） |
| 重新開啟程式後全部重新顯示 | 使用者決定保留關閉狀態（2b；Jev 傾向保留 0.64，信心度 0.28） |
| 切換回放／搜尋時也全部重新顯示 | 使用者決定只有還原預設版面才恢復（3） |
| 選單不加「全部顯示」 | 一個一個開比較麻煩（4b，Jev 0.17） |
| Layout 回放與事件清單不能關 | 使用者要求全部都能關（5b，Jev 0.03） |
| 在 ADR-0008 第 7 點加補充 | 使用者決定另開 ADR（6a；Jev 0.33，信心度 0.34） |

## 尚存風險

| 風險 | 影響 | 因應 |
|---|---|---|
| 關掉的面板中的提示（未對應、異常紀錄、可能卡住的說明等）看不到 | 使用者可能漏看 | 「視窗」選單一直列出所有面板；「還原預設版面」一次恢復 |
| 3D 回放（WebView2）隱藏後重新顯示 | 可能需要重新載入 3D 畫面 | 冒煙測試確認關閉再開啟後 3D 仍載入 |
| 舊版程式存的版面檔標示面板不能隱藏 | 讀入後仍不能關閉 | 讀入版面後一律改為可以隱藏 |

## 後續驗證方式

- 冒煙測試：從「視窗」選單關閉面板後重新開啟程式仍然關閉、從選單開啟回到原位；切換回放／搜尋版面時關閉的面板維持關閉；還原預設版面時全部重新顯示；Layout 回放關閉再開啟後 3D 仍載入。
- 既有的 Docking 版面冒煙測試仍通過。
