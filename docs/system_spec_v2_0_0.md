# 自動化倉儲設備回溯與智慧診斷系統 - 系統規格書 (Ver 2.0.0)

## 1. 系統定位與核心架構
- **專案目標**：打造支援多廠別、模組化，且具備離線 AI 診斷能力的通用倉儲模擬與回溯平台。
- **重繪與效能邏輯 (Event-Driven Rendering)**：
  - PLC 日誌專職負責設備與貨物的「位置移動」(座標更新)。
  - EXE/Server 日誌負責「狀態與屬性更新」(如異常變色，觸發局部重繪，不牽動全域 Layout)。
  - 貨物的「誕生/消失」由「系統命令」與「Sensor 觸發」的日誌交集嚴謹判定。
- **資料庫混合架構**：
  - 關聯式資料庫 (SQLite)：存放正規化後的時序 Log，確保精準撈取特定時間/設備的日誌。
  - 向量資料庫 (Vector DB)：專職作為 RAG 知識庫，存放機台手冊、SOP 等非結構化文件。

## 2. UI/UX 與使用者操作
- **雙模式設計**：
  - 編輯模式 (Editor Mode)：類似 VB.NET 工具箱，支援視覺化拖曳建置 Layout，並支援為設備動態新增 Key-Value 屬性（如 IP、關鍵字）。
  - 播放模式 (Playback Mode)：讀取 Layout 設定檔，並由 Log 驅動畫面與屬性變化。
- **自訂版面配置 (Docking UI)**：
  - 支援多視窗浮動、拖曳與大小調整，完美支援雙螢幕監控。
  - 具備「記憶版面配置」功能，啟動時自動恢復使用者慣用排版。
  - 具備「多設備即時狀態面板」，可同時釘選多台設備並排比對動態屬性。
- **播放控制**：支援常規進度條（含異常熱區標示），並支援使用「方向鍵」進行精準的逐幀（單步事件）播放。

## 3. 日誌管理與證據匯出
- **日誌匯入**：支援自訂本機日誌目錄路徑，系統自動記憶路徑。
- **智慧打包匯出**：
  - 定位關鍵瞬間後，可自訂前後時間範圍進行打包。
  - 支援以「物料 ID」或「命令」為關鍵字，系統自動過濾雜訊，整理出乾淨的搬送軌跡。
  - 雙軌產出物：提供「輕量級 .zip 資料包」（截圖+純文字軌跡）或「視覺化報告書」（PDF/Excel）供使用者選擇。

## 4. AI 賦能與部署策略
- **離線 LLM 應用**：
  - 語意化異常診斷：將生硬錯誤碼（如 E84）轉為人類易讀的故障原因描述。
  - 報告自動總結與翻譯：自動撰寫異常經過，並支援多國語言（如日文）翻譯。
  - 自然語言查詢：支援白話文搜尋（如「找出 F12345 卡住的原因」）轉譯為過濾條件。
- **介面動態連動 (Graceful Degradation)**：系統啟動時偵測 LLM 端點，連線成功顯示 AI 面板；失敗則優雅降級為純手動播放模式。
- **企業級部署**：
  - 採主從式架構：Edge Server 集中算力與容器化 (Docker) 部署 AI/DB。
  - 前端免安裝：打包為單一 `.exe` 獨立執行檔，解決跨 PC 運行的環境相依性問題。
