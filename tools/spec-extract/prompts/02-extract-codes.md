# 02 抽出代碼對照（錯誤碼、狀態碼等）

請整理 **〔章節編號〕（p.〔起〕～p.〔迄〕）** 的代碼一覽，依「00 規則」輸出 CSV。

- 設備種類：〔RM／STV／AGC〕
- 類別：錯誤碼一覽填 `錯誤碼`，狀態一覽填 `狀態碼`，其他依原文的表名（例如 `結果碼`）
- 規格書版本：〔版本或日期〕
- **電文、欄位**：代碼是某個電文欄位的值時（例如完成回報的「結果碼」欄），「電文」填電文 ID、「欄位」填欄位名稱，照抄原文
  - 原文寫明多個電文**共用同一張代碼表**時，代碼**只列一次**，「電文」照原文的寫法（例如 `T20、T30`、`ID21～89`），不要每個電文各列一次
  - 不同電文各有自己的代碼表時，各自列出並分別填電文；同一個代碼在不同電文意義不同是正常的
  - 錯誤一覽、警報代碼等不屬於特定電文的代碼，「電文」「欄位」留空
- 每個代碼一列；同一代碼在原文有多種意義時（例如依設備狀態不同），分成多列並在意義中寫出條件
- 原文表格中有「處置」「原因」欄時，接在「意義（原文）」後面，以「／原因：…／處置：…」分隔

完成後告訴我：這個範圍共整理幾列、有幾張代碼表是多個電文共用的、有幾列標了「〔跨頁，請確認〕」、有沒有看不清楚的地方。
