# 03 抽出電文與欄位定義

請整理 **〔章節編號〕（p.〔起〕～p.〔迄〕）** 的電文定義，依「00 規則」輸出 CSV。

- 設備種類：〔RM／STV／AGC〕
- 規格書版本：〔版本或日期〕
- 每個**電文**一列：類別填 `電文`，代碼或名稱填電文名稱或電文 ID，意義寫用途與傳送方向（例如「WCS → RM：搬送指示」）
- 每個**欄位**一列：類別填 `欄位`，代碼或名稱寫成 `電文名稱.欄位名稱`，意義寫位置、長度、型態與內容說明（例如「第 11～14 位元組，ASCII 4 碼，命令編號」）
- 欄位的值有代碼對照時，代碼本身請另外用「02 抽出代碼對照」整理

完成後告訴我：電文幾個、欄位幾列、有沒有欄位位置或長度對不起來的地方。
