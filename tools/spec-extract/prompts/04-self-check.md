# 04 自我檢查（每批結束後貼）

請逐列檢查你剛才輸出的 CSV，只修正有問題的列，再輸出一次完整的 CSV：

1. 每一列都有「出處」與頁碼嗎？沒有的補上；找不到出處的整列刪除並告訴我。
2. 代碼或名稱是否和原文一字不差（大小寫、全形半形、補零）？
3. 有沒有重複的列？完全相同的只留一列；同一代碼但意義不同的兩列都保留，並告訴我是哪幾個代碼。
4. 跨頁的表格：每一列的欄位有沒有錯位？不確定的在「意義（原文）」最後加「〔跨頁，請確認〕」。
5. 日文原文的列：「意義（中文）」都有翻譯嗎？翻譯有沒有加入原文沒有的內容？
6. 有沒有任何內容是你推測的？有的話改成「待確認」。

最後回報統計：總列數、修改幾列、刪除幾列、標示〔跨頁，請確認〕幾列。
